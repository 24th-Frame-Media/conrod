## Fix batches (proposed)

### A. Crash/robustness (Rust, no accuracy risk)
- A1 `conrod-io/src/raw.rs:407-411` CR3 top-level walk indexes `head[8..16]` on a short read (truncated file panics); `(size - header) as usize` from the file can allocate huge. Check length, cap moov size, `checked_add`.
- A2 `raw.rs:345-366` `boxes()` uses `at + size` on file-supplied u64->usize; can wrap in release. Use `checked_add` / `size > buf.len() - at`.
- A3 `conrod-io/src/vlm.rs:222` `Retry-After: inf`/`1e308` -> `Duration::from_secs_f64` panic (`vlm.rs:142`). Reject non-finite, clamp to MAX_WAIT.
- A4 `conrod-engine/src/lib.rs:719` `detector.lock().unwrap()` -> poison-tolerant `lock()` helper; same for `conrod-core/src/tasks.rs` (5x), `conrod-store/src/lib.rs:337`, `passes.rs:1045`, `operations.rs:636`.
- A5 Swallowed DB writes: `desktop.rs:956-959, 1051-1058`, `rescore.rs:222-235` (`let _ =`, `unwrap_or_default()` writes `""` features).

### B. Security hardening (Rust)
- B1 `DescribeImage{path}` (`bench.rs:31`, `desktop.rs:536`) reads any path and sends its preview to the cloud VLM. Restrict to album frames in the DB.
- B2 Gemini key in URL query (`vlm.rs:~882`) -> `x-goog-api-key` header.
- B3 `save_settings` accepts `extra.map_path`, later read as an arbitrary file (`settings.rs:540-551`, `catalog.rs:221-227`). Drop `extra` from webview saves or confine to data_root.
- B4 `ProviderModels` sends the API key as Bearer to a webview-supplied host, no timeout (`desktop.rs:431-440`, `vlm.rs:707-734`).
- B5 Dead `conrod-io/src/update.rs` (checksum-only installer path, unused since the Tauri updater). Delete.
- B6 CSP: add `object-src 'none'; base-uri 'self'` (`tauri.conf.json:26`).
- Deferred (larger): API key plaintext in `~/.conrod/settings.json` and returned to the webview in Bootstrap -> Windows Credential Manager. exiftool bare-PATH fallback.
